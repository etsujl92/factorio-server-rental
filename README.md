# 异星工厂服务器租用：单核性能、内存和带宽怎么选，从 2 人到 10 人联机的配置对照

异星工厂的联机开服，坑往往不在"能不能开"，而在"开起来之后为什么越来越卡"。很多人第一次租服务器，会照搬《我的世界》的经验去买 8 核 32G，结果发现工厂一进入中后期，UPS 还是从 60 掉到 30，画面里的传送带像慢动作回放。

原因在于这款游戏的技术特性。

## 异星工厂的服务端，吃的是单核不是核数

专用服务端（dedicated server）是官方提供的 headless 版本，没有图形界面，所以你完全不需要显卡。游戏逻辑以 60 UPS 运行，而这套逻辑基本压在单个线程上。传送带、机械臂、熔炉、火车、机器人的每一次更新都在这个线程里排队。

这带来两个直接后果：

- **核心数买到 16 核没有意义**，除非你同时开好几个服。决定 UPS 的是那颗 CPU 的单核主频和单核跑分。
- **内存需求比想象中低**。小地图几个人玩，2GB 到 4GB 就能跑；只有在装了大量 mod、地图铺得很开的时候，内存压力才明显。

Factorio 官方给出的服务器最低/推荐配置是 3GHz+ 主频、四核 CPU、8GB 内存起步，推荐 16GB。这个数字偏向"给大地图留足余量"的口径，不是小型联机的真实占用。

端口方面，异星工厂游戏流量只走 **UDP 34197**，开服时把它放通就行。RCON 可选，走单独的 TCP 端口。另外自动存档会定期写盘，地图越大存档越大，磁盘写入速度对"存档时全体卡一下"的体感影响不小——NVMe 比 SATA SSD 更省心。

所以租服务器的优先级排序是：**单核性能 > 内存 > 磁盘 I/O > 带宽**。带宽排最后，因为异星工厂的同步数据量小，10Mbps 撑几个人联机并不吃力，真正需要大带宽的是公网 IP 稳定性和抗攻击能力。

## 租用前先想清楚：你要哪种计费方式

这是最容易多花钱的环节。

大多数国内游戏云服务商有两条计价路线：固定月租（按配置一口价）和动态计费（基础月租 + 按实际 CPU 消耗日结）。以雨云游戏云为例，它的动态计费模式是以 CPU 使用率 20% 为基准线，超过 20% 的部分按"CPU 电量"每日结算，内存、硬盘等不产生额外电费。

换算成实际选择：

| 你的玩法 | 更适合的计费 | 理由 |
| --- | --- | --- |
| 每天固定上线 2 小时以上 | 固定计费 | 跑得久，动态计费的日结会累加，固定月租更可预期 |
| 周末偶尔开一局，平时关服 | 动态计费 | 闲置时几乎不产生额外费用 |
| 刚上手，想先摸清服务器能扛多少 | 动态计费 + 1 元试用 | 试错成本最低 |

"每天 2 小时"这条线来自公开的配置整理文章，属于经验阈值，不必当成硬性规则——工厂越大、同时在线的人越多，CPU 占用越高，动态计费的优势就越小。

## 雨云的游戏云方案：面板版和 VPS 版怎么选

雨云成立于 2018 年，持有工信部颁发的 ISP、IDC、CDN 经营许可，产品线里和异星工厂相关的主要是**游戏云面板**和**游戏云 VPS**两条。

两者最大的区别在于"谁来负责部署"。

**游戏云面板**是雨云自研的管理面板，主打一键开服、CPU 升降级、可视化管理、备份和 MySQL 功能。它的定位更偏向《我的世界》这类有成熟服务端管理需求的游戏——选好配置和整合包就能开，不需要敲命令行。如果你完全不想碰 Linux，这是门槛最低的路。

**游戏云 VPS** 给你一台完整的 Linux 或 Windows 机器，装什么、怎么装都自己决定。异星工厂的专用服务端需要自己下载、配置 `server-settings.json`、管理 mod 列表和存档，这些操作在 VPS 上做最直接。

对于异星工厂，**VPS 版通常更合适**。原因不是面板功能不行，而是这款游戏的服务端需要你频繁切换版本、手动指定 mod 列表的版本号、调整地图生成参数，自己掌控环境反而更省事。

另外几个实际参数值得记一下：

- **线路与防御**：雨云的游戏云产品线以 BGP 高防线路为主，各地节点防御等级不同。异星工厂私服一般不会被打，但高防线路顺带带来的是路由质量，对跨运营商联机的延迟改善更明显。
- **NAT 机型与端口映射**：部分机型是 NAT 机，需要和别人共用公网 IP，通过端口映射对外暴露服务。这对异星工厂完全够用——你只需要映射一条 UDP 34197。但如果你不想每次分享房间都带着端口号，可以考虑加购独立公网 IP。
- **退款与试用**：官方规则是 7 天内无理由退款（每个账号限 3 次），云服务器和游戏云产品支持 1 元试用一天（每款限 1 次，较贵的机型试用价会高一些）。不确定配置够不够，先花 1 元跑一天比看参数表靠谱。

## 按人数挑配置：一个务实的对照

把上面的信息落到具体场景：

**2–4 人，原版或轻 mod**
2核 4G 完全够用。动态计费机型月成本能压到几十元以内，面板方案的入门档 25 元/月起就是这一类。要留意的是后期工厂规模——当传送带和机器人数上千，单核压力会显著上升。

**4–8 人，Space Age 或中等 mod 包**
优先挑高主频机型，4核 8G 起。这一档的关键不是核心数翻倍，而是换一颗单核更强的 CPU。W9-3495X、Ryzen 7950X/9950X、i9-14900K 系列都是这个逻辑下的选择，公开评测里它们的单核跑分差距会直接反映到 UPS 上。

**10 人以上或追求 megabase**
6核 12G 起步，往 8核 16G 以上走。这里要开始关心带宽和端口映射的便利性，NAT 机型建议直接加购独立公网 IP。

值得一提的是，雨云各节点的库存不完全同步，热门机型（尤其是高主频的 i9 和 9950X）会出现暂时缺货的情况，下单前在配置页确认一下当前可选项比较省事。

## 部署流程：从买到能连上

假设你选的是 VPS 方案，整体流程是这样的：

1. **选购**：在游戏云下单页选择机型、区域、计费模式、核心/内存/带宽/硬盘规格，选择 Linux 系统，指定公网 IP 方式（NAT 或独立 IP）。
2. **放通端口**：在控制台找到端口映射设置，把内网的 **UDP 34197** 映射出去。NAT 机型这一步必须做，独立 IP 机型确认防火墙放行即可。
3. **下载服务端**：从官方下载 headless 版本，解压后是完整的服务端目录。也可以走 SteamCMD 安装 appid 427520。
4. **建图并启动**：先 `--create saves/world.zip` 生成存档，再用 `--start-server saves/world.zip --server-settings server-settings.json` 启动。想要后台常驻，用 screen 或 tmux 挂着。
5. **配置服务端**：`server-settings.json` 里改房间名、描述、最大玩家数、是否公开列表、是否需要正版验证、自动存档间隔和保留份数。改完重启生效。
6. **装 mod**：把 mod 压缩包放进 mods 目录，`mod-list.json` 控制启用列表。注意服务端和每个玩家的版本、mod 版本必须一致，否则连不上。
7. **备份**：存档目录定时打包到另一块盘或对象存储。异星工厂一次误操作毁掉几百小时工厂的事故不算罕见。

如果你不想碰命令行，面板方案能省掉 3 到 7 步的大部分操作，代价是灵活性差一些。

## 常见问题

**服务端一定要用 Windows 吗？**
不用。官方 headless 版本在 Linux 上跑得更好，资源占用也更低。VPS 方案选 Debian 或 Ubuntu 都可以。

**带宽 10M 够几个人？**
异星工厂的同步数据量不大，10Mbps 对个位数玩家规模是够的。真正的瓶颈几乎总是 CPU 单核。

**NAT 机型和独立 IP 差别大吗？**
功能上没区别，NAT 机型通过端口映射对外提供访问，只是分享给朋友时地址后面要带端口号。加购独立公网 IP 的好处是地址固定、方便反复邀请人，代价是每月多一笔固定支出。

**面板方案能不能开异星工厂？**
面板的主打场景是《我的世界》这类有成熟一键部署流程的游戏。异星工厂因为涉及版本切换、mod 列表管理和地图生成参数，走 VPS 自行部署会更顺畅；如果你更看重省事，可以先用面板熟悉一下操作逻辑，再决定要不要换成 VPS。

**服务器卡了怎么办？**
先看 UPS 而不是 TPS。UPS 掉到 60 以下说明单核算力不够，这时候降 mod 数量、缩小地图范围或减少同时在线的玩家数量都能缓解；如果确定是配置问题，雨云游戏云支持在控制台升降级配置。
